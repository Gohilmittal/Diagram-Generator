# Diagram Generator

A data-driven system that automatically generates accurate SVG/PNG diagrams from structured JSON, supporting 8 different diagram types with visual matching to reference designs.

## 🎯 Features

- **8 Diagram Types**: Bar, Pie, Line, Circular, Linear, Directional, Venn, and Blood Relation Tree
- **JSON Input**: Structured JSON with validation
- **SVG Output**: Clean, scalable SVG generation
- **PNG Export**: Download diagrams as PNG images
- **Interactive UI**: Preview, validate, and export diagrams
- **Sample Data**: Pre-built samples for all diagram types
- **Modular Architecture**: Independent renderers for each diagram type
